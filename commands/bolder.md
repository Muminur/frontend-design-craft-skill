# /bolder

The design is technically correct but boring. It looks like every other SaaS site. Push it.

## Target

$ARGUMENTS

## Procedure

1. **Diagnose the boring.** What specifically makes it generic? Likely candidates:
   - Centered hero with predictable structure
   - Safe blue or corporate-purple color
   - Conservative type sizes (everything between 16px and 36px)
   - Symmetric grids only
   - No personality in copy
2. **Pick one bold lever first.** Do not push everything at once.
   - **Typography lever:** Increase display sizes dramatically (96px+ headlines), introduce a serif for emotional moments, or commit to a single distinctive face.
   - **Color lever:** Replace safe blue with a confident non-default — deep green, terracotta, oxblood, electric blue at lower saturation, sand.
   - **Layout lever:** Break the centered hero. Use a 7/5 asymmetric split. Put the headline at an unexpected scale or position.
   - **Density lever:** Either way more whitespace, or way more density — both feel intentional.
3. **Commit.** Half-bold reads as confused. If you raise the headline to 96px, also raise its weight, also tighten the tracking, also reduce surrounding noise.
4. **Re-check restraint elsewhere.** When one element gets bold, others must get quieter. A bold headline next to a busy background is just chaos.

## Output

```
## Bolder

**Lever pulled:** [typography | color | layout | density]
**Specific changes:**
  - [list]
**Restraint applied to balance:**
  - [list of things that were toned down]
```
